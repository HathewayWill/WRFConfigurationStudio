# Shared utilities

This folder is reserved for shared first-party utilities that may be extracted from the current source files when the application is modularized further.

Candidate future utilities include:

- `tooltips.js`
- `storage.js`
- `dom.js`
- `formatters.js`

Current runtime behavior remains in the existing first-party source files under `src/core/`, `src/namelist/`, and `src/tools/`.
