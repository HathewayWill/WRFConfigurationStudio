# WPS helper ownership

This folder is reserved for a future internal split of the WPS helper system.

Candidate future modules include:

- `wps-helper-config.js`
- `wps-helper-ui.js`
- `wps-helper-export.js`

Current WPS helper behavior is implemented in `src/tools/wps-tools.js` and the domain-map layer under `src/core/`.
