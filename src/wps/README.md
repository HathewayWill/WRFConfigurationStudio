# WPS helper ownership

This folder is reserved for the next internal split of the WPS helper system:

- `wps-helper-config.js`
- `wps-helper-ui.js`
- `wps-helper-export.js`

For this structure-baseline build, runtime behavior is preserved from the prior beta and remains
owned by the reorganized first-party files under `src/core/` and `src/tools/`.
