# Publication layout

Current `main` is organized as the polished publication layout.

## Included

- application entry files
- `src/`
- `styles/`
- `vendor/`
- `images/`
- `data/runtime/`
- `data/raw/`
- `examples/`
- `docs/user-guide/`
- `docs/references/`
- `docs/references/legacy_source_docs.zip`
- `docs/release-notes/`
- final validation tools under `tools/`

## Excluded from current main

Development-only compatibility audit reports, promotion scripts, triage scripts, mining scripts, and temporary audit outputs were removed from the current tree.

They remain recoverable through Git history and prior stable tags.
