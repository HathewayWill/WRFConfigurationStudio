# WRF Configuration Studio Project Lineage

This document records project lineage and credit information for WRF Configuration Studio.

## Summary

WRF Configuration Studio acknowledges three connected layers of project history:

1. NOAA/FSL's early WRF Standard Initialization GUI work, which demonstrated a graphical workflow for WRF domain localization and initialization setup.
2. Jiří Richter's original WRF Domain Wizard, which provided the direct foundation and first-generation implementation for this browser-based lineage.
3. WRF Configuration Studio, the current browser-based continuation focused on WRF domains, namelist editing, WRFDA, OBSPROC, Registry metadata, and validated compatibility-rule guidance.

## NOAA/FSL WRF SI GUI acknowledgment

WRF Configuration Studio acknowledges the earlier NOAA Forecast Systems Laboratory / Forecast Systems Laboratory WRF Standard Initialization GUI work by Paula T. McCaslin, John R. Smart, Brent Shaw, and Brian D. Jamison.

That work demonstrated a graphical workflow for WRF domain localization, projection and grid editing, initialization setup, and user guidance, and it is part of the technical lineage behind later WRF domain tools.

## WRF Domain Wizard acknowledgment

The original WRF Domain Wizard project by Jiří Richter remains credited in the About section and project documentation. Internal source names may still use WRF Domain Wizard terminology where required for compatibility with existing code hooks.
